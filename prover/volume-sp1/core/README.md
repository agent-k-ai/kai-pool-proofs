# kai-volume-core

Portable pure Rust primitives for the provisional SP1 volume relation:

- Explicit frozen terms (136 Solidity ABI words) and strict journal (25 words /800 bytes).
- Strict16-field Nitro header RLP parsing and full Ethereum Keccak hash.
- Pinned Uniswap V4 (kind1) and Uniswap V3 (kind2) Swap qualification and checked uint256 volume/count accumulation over decoded log views.

Read [CORE-INTERFACE.md](CORE-INTERFACE.md) for the contract with receipt/trie/guest callers.
This is **not a SP1 guest, receipt/trie verifier, recursive aggregator, proof, wallet, or financial implementation**.
No code in this package fetches RPC data, signs or submits transactions. A structurally valid journal is not an authenticated proof.

## Native tests

```sh
cargo test --locked --lib --tests -- --test-threads=2
cargo clippy --locked --all-targets -- -D warnings
cargo fmt --check
```

Use `--offline` with an already populated Cargo cache. This implementation was tested natively with Rust1.94.1; no guest-target build is claimed.
No funding rate or default deployment address is selected. Synthetic identity/policy values are tests only.

## Independent vectors

`test-vectors/abi-vectors.json` is generated by viem2.56.1's ABI/RLP/Keccak implementation, independently of the Rust codec.
It covers3/4/8-entrant terms/journals, both token sides, signed boundaries, every entrant's accumulation, malformed header cases and kind-2 (V3) terms with int256 swap vectors on both quote sides.
The real550-byte header/decoded-log fixture is block117903561 on chain46630. Tests verify the recorded hash/root and a1e15 raw native quote amount.
`test-vectors/v3-swap-4663-64028601.json` is one real, read-only captured Uniswap V3 `Swap` log of the mainnet (chain4663) PONS/WETH pool `0xed50bdee…` at block64028601; tests verify the pool-perspective int256 deltas and the WETH quote magnitude.
Synthetic surrounding terms and minimum notionals are not an attested real race.

To regenerate, provide an existing viem2.56.1 installation resolvable by Node:

```sh
node test-vectors/generate.mjs
```

`VIEM_MODULE` may name that installation's ESM entry URL if it is outside normal module resolution. The generator performs no install or network call.
SOURCE-ORIGINS.json, NOTICE and fixture metadata record extraction provenance. Other C1 repository components retain their separate review status.
